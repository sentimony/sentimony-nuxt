# Function invocation budget

- Status: Idea
- Priority: P1
- Ініційовано: 2026-08-11
- Last reviewed: 2026-08-11
- Related: [origin response time](origin-response-time.md), [аудит 2026-08-11](../audits/2026-08-11-branch-vs-prod-perf-audit.md), [cloudflare domain](cloudflare-domain.md)

## Навіщо

Free-план Netlify дає 125 000 викликів функцій на місяць. 2026-08-01 команда
перевищила ліміт: `usages_exceeded: [{usage_type: "functions"}]`, а
`sites_with_usage_exceeded` містить рівно один сайт — `sentimony-nuxt`. Решта 29
сайтів команди статичні й функцій не викликають.

Наслідок перевищення несиметричний до причини: пауза накриває **всі** сайти
команди, включно з `content.sentimony.com`, звідки йдуть усі обкладинки й фото.
Тобто разом із SSR відвалилися б і всі зображення на сайті. Це переводить
питання з площини швидкості в площину доступності.

[Origin response time](origin-response-time.md) прибрав найгрубіші джерела
викликів (durable-кеш, query-стабільний ключ, добовий TTL HTML, публічний
`GET /api/track-plays`). Ця ініціатива — про те, що лишилось, якщо цього
виявиться мало.

## Очікуваний результат

Місячна кількість викликів має вимірюваний запас до ліміту, і цей запас видно
без відкриття панелі Netlify.

## Обсяг

Кандидати, від дешевого до дорогого:

- **TTL counter-роутів.** Зараз `public, max-age=60, stale-while-revalidate=300`
  на `*/count/**` і `GET /api/track-plays`. Верхня межа — 1440 викликів на добу
  на сторінку, до якої є трафік щохвилини. Лічильники лайків і відтворень не
  потребують хвилинної свіжості; 5–15 хвилин зменшують стелю в 5–15 разів.
- **Prerender каталогу.** `routeRules: { prerender: true }` на списках і
  detail-сторінках дає нуль викликів функцій для них ціною ребілду на кожну
  зміну контенту. Найбільший ефект і найбільша зміна в робочому процесі:
  контент зараз редагується в `sentimony-db.yml` і синкається без деплою.
- **Вимірювання.** Наразі фактичне число викликів недоступне через API
  (`capabilities.functions.used` віддає 0), тому запас оцінюється непрямо.
  Потрібен спосіб бачити тренд, інакше наступне перевищення знову буде
  сюрпризом.
- **Nitro cache storage на Netlify Blobs.** Нова залежність `@netlify/blobs`,
  деталі в [спеці origin response time](../superpowers/specs/2026-08-11-origin-response-time-design.md).

## Залежності

Prerender конфліктує з поточною моделлю контенту: `sync:supabase` оновлює дані
без деплою, а prerendered HTML про це не дізнається. Перед вибором цього шляху
треба вирішити, чи зміна контенту тригерить білд.

## Критерії завершення

- Відомо фактичне місячне число викликів і запас до 125 000.
- Detail-сторінка не породжує жодного некешованого виклику функції.
- Рішення щодо prerender ухвалене явно: або впроваджено, або відхилено з
  зафіксованою причиною.
