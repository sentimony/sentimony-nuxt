## Навіщо

Після базового рівня доступності (лендмарки, фокус, імена контролів, стани
списків) повторний аудит знаходить наступний шар: треклісти й списки зв'язків
як `<p>` замість `<ol>`/`<ul>`, alt-тексти, що дублюють текст посилання або
дорівнюють URL файлу, iframe без `title`, неоголошений `color-scheme`, три
списки без станів, повзунок міксу без імені, контраст, з'їдений накладеною
прозорістю, і кольори поза токенами.

## Очікуваний результат

Read-шар каталогу (сім детальних сторінок, `/tracks`, `/releases/all`,
`/artists/all`) має списочну семантику, чисті доступні імена, стани для
кожного списку, два текстові тири без накладеної прозорості й палітру без
хардкоджених значень — без зміни композиції.

## Обсяг

- Списки: `<ol>`/`<ul>` + `<li>` для треклістів, лайнапів і списків зв'язків.
- Імена: `alt=""` для зображень у посиланнях із текстом; `title` на кожному
  iframe; `aria-label` на повзунку міксу.
- Стани: `CollectionStatus` на трьох списках, що лишилися.
- Розміри зображень, `color-scheme`, токени `--color-moss`, спільні
  градієнти головної, одна карта висот iframe-ів.
- Контраст: без `opacity-*` на тексті в приглушеному контейнері, футер на
  `text-white/70`, hover на `/artists/all` через токен.
- Копірайт: «Related», латинська «Credits», одна заглушка «Coming soon»,
  `<h1>` головної з повною назвою.

## Залежності

- [accessibility-structure](accessibility-structure.md) — базовий рівень,
  на який спирається.
- Снапшоти `homepage-theme.spec.ts` оновлюються свідомо після перевірки
  diff-зображень.

## Критерії завершення

- Юніт-тести по джерелу закріплюють кожен пункт обсягу — виконано
  (`catalogSemantics`, `accessibleNames`, `collectionStatus`,
  `interactionStates`, `landmarks`).
- `npm run test:e2e` зелений (2026-09-05). Десять падінь, що були на
  базовому коміті, зняті після рев'ю: еталони головної від 2026-06-25
  застаріли ще наступного дня (`44efa83`: uppercase-навігація з ширшим
  трекінгом, інші іконки хедера), а Chromium перейшов з 1228 на 1234 разом із
  Playwright 1.61 → 1.62; жоден зсув на 1px не зменшував diff, тож макет не
  чіпали, а еталони перезнято без DevTools;
  `api-security` тепер очікує 200 від `/api/release/<hidden>` і
  `/api/artist/<hidden>` (детальні маршрути навмисно читають без фільтра
  `visible`) і 404 від решти; тести forest-asset очікують `.jpg`, який
  віддає `forest-bg.client.ts`.
- Повторний аудит не знаходить T12–T22, V7–V9, V11 відкритими — виконано
  2026-09-04.
